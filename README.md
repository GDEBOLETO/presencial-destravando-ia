## 🚀 Deploy no GitHub + Vercel

1. Crie um repositório no GitHub e suba **todos** os arquivos desta pasta (incluindo o `index.html`).
2. Na Vercel: **Add New → Project** → importe o repositório → Framework Preset **Other** → **Deploy**.
3. Em ~30s a página está no ar. Cada `push` na branch `main` republica automático.

Domínio próprio: Vercel → projeto → **Settings → Domains**. SSL automático.
